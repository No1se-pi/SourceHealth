# Как применить изменения

GitHub-подключение в текущем чате имеет доступ на чтение, но GitHub API вернул
403 `Resource not accessible by integration` на операции записи.

В архиве лежат готовые замены файлов с русской документацией и комментариями.

## Вариант 1 — вручную

1. Переключитесь на ветку:

   git checkout Dev-No1se

2. Распакуйте содержимое архива поверх корня репозитория с заменой файлов.
3. Проверьте изменения:

   git diff

4. Запустите тесты:

   python -m unittest discover -s tests -v

5. Закоммитьте:

   git add README.md docs sourcehealth tests test
   git commit -m "docs: русифицировать документацию SourceHealth"
