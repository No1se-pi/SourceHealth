# Submission checklist

- [ ] PR открыт в `Dev-No1se`, merge выполняет владелец.
- [ ] Large-repo final run записан безопасными агрегатами.
- [ ] AppSec отмечен PASS только по текущему production acceptance.
- [ ] `/demo` подписан `DEMO DATASET / OFFLINE DEMO` и не включается автоматически.
- [ ] Production URL `https://sourcehealth.tech` проверен владельцем.
- [ ] Screenshots и видео не содержат PAT, OAuth secrets, cookies, `.env`, private repos или source snippets.
