# Screenshot index

Для submission выбрать 5–8 кадров:

1. Live leaderboard — публичные repository cards.
2. Repository analysis — Health и coverage.
3. Шесть category cards с `NO_DATA` для недоступного AppSec.
4. Evidence и recommendations.
5. Markdown report download.
6. Large-repository acceptance summary.
7. Явно помеченный `DEMO DATASET / OFFLINE DEMO` (только как fallback).

Каждый кадр подписать как `live`, `fixture` или `offline demo`; не смешивать эти режимы.
