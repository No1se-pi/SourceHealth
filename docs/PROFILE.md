# Профиль и SourceCraft PAT

`/profile` доступен после входа через Яндекс ID. Профиль показывает доступные текущему SourceCraft PAT репозитории через официальный `GET /me/repos`, отслеживаемые публичные проекты, Health, предварительный Source Soul только при отсутствии Health, следующее обновление и достижения.

Private/internal репозитории отображаются транзитно только владельцу текущей сессии. Они не сохраняются в публичном каталоге, не получают badge и не анализируются.

PAT никогда не попадает в PostgreSQL, browser storage, API response или RQ payload. Он проверяется через SourceCraft, шифруется AES-GCM со свежим nonce и user-bound AAD и хранится в Redis. Разрешены сроки 30 минут, 6 часов, 24 часа и 7 дней. Значение по умолчанию — 30 минут. При явном выборе большего срока выход завершает веб-сессию, но credential остаётся до истечения TTL для разрешённого автоанализа. «Удалить PAT сейчас» удаляет его немедленно.

Для каждого отслеживаемого проекта пользователь отдельно выбирает частоту и разрешение использовать retained PAT для официального AppSec. По умолчанию разрешение выключено. Планировщик выбирает один credential детерминированно; в job остаётся только `analysis_id`.

Кнопка «Отслеживать» использует этот же session-scoped PAT для краткой проверки public
repository metadata перед import. PAT не становится глобальным и не разрешает private
analysis. Ошибка import показывается рядом со списком, новый клик создаёт новый POST и
заменяет предыдущий request ID; pending-состояние всегда снимается в `finally`.

Достижения вычисляются из сохранённой истории после даты начала отслеживания и не влияют на Health, Source Soul, leaderboard или рекомендации.
