# Углублённая аналитика репозитория

`repository_insights` — дополнительная проверка профиля `mvp-v1`. Она показывает концентрацию
изменений, приблизительный Bus Factor, распределение владения верхнеуровневыми областями и
гигиену репозитория. Проверка не является седьмой категорией, не входит в `mvp-score-v1.2`,
не меняет Health Score и его coverage.

## Границы и приватность

- История contributors ограничена 5000 коммитами. При превышении лимита
  `history_complete=false`, а результат явно считается выборкой.
- Ownership использует не более 1000 коммитов, 20 000 наблюдений путей и публикует не более
  20 верхнеуровневых групп.
- Bus Factor proxy — минимальное число участников, давших не менее 50% наблюдаемых коммитов.
  Это оценка концентрации изменений, а не знаний команды. При выборке меньше пяти коммитов
  значение равно `null`, причина — `insufficient_commit_sample`.
- Имена, email и сообщения коммитов существуют только в памяти изолированного анализатора.
  В JSON, БД, API, Markdown и UI попадают только `Contributor N`, агрегаты и безопасные пути
  верхнего уровня. Source snippets не сохраняются.
- Git вызывается фиксированными аргументами без `shell=True`, hooks и выполнения кода целевого
  проекта. Все операции используют общий runtime deadline.

## Ownership и repository hygiene

Ownership выводится из наблюдаемых Git-изменений и не заменяет CODEOWNERS. Snapshot за один
обход распознаёт `SECURITY.md`, `CONTRIBUTING`, `CODEOWNERS`, SourceCraft branch/review/license
policy, известные dependency manifests, lockfiles и Dependabot/Renovate. Зависимости не
устанавливаются и package registries не вызываются.

Отсутствие файла публикуется как `false` только при полном snapshot. При неполном обходе
неподтверждённое отсутствие становится `null`: `NO_DATA` не равно отсутствию.

## Рекомендации

Детерминированные правила формируют действия для высокой концентрации contributors/ownership,
отсутствующих policy-файлов, CONTRIBUTING/CODEOWNERS, lockfiles и automation. Каждая рекомендация
ссылается на evidence и описывает влияние на сопровождаемость без обещаний прироста баллов.

Review analytics не добавлены: текущие собранные Pull Request facts не содержат подтверждённых
данных о review и времени первого review. Для этого нужен документированный SourceCraft contract.

## Производительность

В check сохраняется `deep_analytics_ms`. Git-выборки и количество публикуемых элементов ограничены;
превышение лимита даёт честную partial completeness. Локальный benchmark на синтетическом
репозитории с 250 коммитами, 8 авторами и 4 верхнеуровневыми группами занял 266 мс по встроенной
метрике (258 мс внешнего wall clock) на Windows development host 27 сентября 2026 года. Это
измерение конкретного запуска, а не SLA.
