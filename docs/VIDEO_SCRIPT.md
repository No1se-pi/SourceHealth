# Video click-path

1. Открыть leaderboard и показать подпись `NO_DATA ≠ 0`.
2. Открыть публичный repository и latest analysis.
3. Показать шесть категорий, coverage, evidence и recommendations.
4. Скачать Markdown report.
5. Открыть `/demo` только если live stand недоступен; на экране должна быть видна маркировка `DEMO DATASET / OFFLINE DEMO`.

Не показывать PAT, OAuth экран после ввода credentials, `.env`, browser profile, private repository или raw source snippets.
