# Video click-path

1. Открыть `https://sourcehealth.tech` и leaderboard.
2. Открыть публичный репозиторий и latest analysis.
3. Показать Health, coverage, evidence, recommendations и Markdown download.
4. При недоступности live stand открыть `/demo`; явно показать `DEMO DATASET / OFFLINE DEMO`.

Не показывать PAT, OAuth secrets, cookies, `.env`, private repositories или source snippets.
